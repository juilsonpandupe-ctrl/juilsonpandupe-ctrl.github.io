# 🎓 EduLearn - eLearning & Course Management Platform

Uma plataforma web moderna para gestão e visualização de conteúdos de aprendizagem e-Learning, desenvolvida como projeto prático demonstrativo para soluções EdTech.

## 🚀 Funcionalidades
- **Listagem Interativa de Módulos:** Apresentação dinâmica de cursos por áreas de especialização.
- **Filtro em Tempo Real:** Pesquisa rápida por nome do curso ou formador.
- **Categorização:** Separação por tópicos (Desenvolvimento Web, Bases de Dados, Segurança & IAM).
- **Acompanhamento de Progresso:** Barras de estado visuais por utilizador.
- **Design Totalmente Responsivo:** Otimizado para telemóveis, tablets e computadores.

## 🛠️ Tecnologias Utilizadas
- **HTML5 & CSS3** (Estrutura semântica e estilização)
- **Tailwind CSS** (Framework de utilitários para interface moderna)
- **JavaScript (ES6+)** (Manipulação do DOM e lógica de filtragem)
- **FontAwesome** (Iconografia técnica)
